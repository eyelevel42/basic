# 대관·카페 정산 자동화 설계

> 구현: `apps-script/` · 설치·사용법: 저장소 루트 `README.md`

## 0. 관계자

| 역할 | 대상 | 소통 채널 | 시스템 연동 |
|---|---|---|---|
| 대관 고객 | 바이스퀘어 조남규 대표 (namgyu@bysq.co.kr) | 카톡 1:1 / 메일 | 메일 자동 발송·회신 파싱 |
| 세금계산서 발행 | 반투소프트 이근영 대표, 김동환 대표 | 카톡 단톡방 | 붙여넣기용 문구 생성 |
| 음료 판매·정산 | 카페42 (마켓샐러드 법인) | 카톡 / 현장 | 붙여넣기용 주문·정산 문구 생성 |
| 운영 | 42maru 대관 담당 | — | 알림 메일 수신 |

메일 연동 대상은 조남규 대표 한 명입니다.

## 1. 전체 흐름

```
[1] 일정 협의 (조남규 대표, 카톡 1:1 또는 메일)
      │  확정: "10/10 14:00~17:00 대관"
      ▼
[자동] [대관확정] 메일 또는 시트 메뉴 입력 → 대관원장 등록 + Google Calendar 등록
      ▼
[2] 반투소프트 단톡방용 세금계산서 요청 문구 생성 (대관료 400,000 + 부가세 40,000)
      ▼
[3] D-4 09시 조남규 대표에게 [음료요청] 자동 메일
      │  회신: "커피 25 / 티 25" (카톡으로 받으면 시트 메뉴로 입력)
      ▼
[자동] 음료주문·일별정산 기록 → 카페42 전달용 주문·정산 문구 생성
      │  (D-1까지 회신이 없으면 담당자 알림)
      ▼
[대관 당일] 현장 POS 결제 (카페42) — 정산은 주문 수량 기준이라 POS 내역 불필요
      ▼
[월초] 전월 정산 합계 리포트
```

## 2. 채널별 연동 범위

| 채널 | 읽기 | 쓰기 | 처리 방식 |
|---|---|---|---|
| Gmail | ✅ | ✅ | 자동화의 기준 채널 |
| Google Calendar / Sheets | ✅ | ✅ | 원장·일정·정산 |
| 카톡 1:1 / 단톡방 | ❌ | ❌ | 개인 대화방 공식 API 없음 → 시트 메뉴 입력 + 문구 복사 |

## 3. 메일 규칙

| 단계 | 제목 형식 | 보내는 사람 → 받는 사람 |
|---|---|---|
| 일정 확정 | `[대관확정] 2026-10-10 14:00-17:00 바이스퀘어` | 담당자 → 조남규 |
| 음료 요청 | `[음료요청] 2026.10.10(토) 14:00~17:00 바이스퀘어 음료 수량 확인 #R20261010-1` | 시스템 → 조남규 |
| 음료 회신 | 위 메일에 회신. 본문 `커피 25`, `티 25` | 조남규 → 시스템 |

`#R…` 대관ID로 회신과 대관 건을 연결합니다. 수정 회신이 오면 최신 수량으로 다시 계산합니다.

## 4. 데이터 구조 (Google Sheet `대관 관리`)

| 탭 | 내용 |
|---|---|
| 대관원장 | 대관ID, 일시, 주말 여부, 대관료(공급가·부가세·합계), 상태, 단계별 처리일 |
| 단가표 | 메뉴, 판매가, 원가 (커피 3,500/1,100 · 티 2,500/800) |
| 음료주문 | 대관ID별 메뉴·수량 |
| 일별정산 | 결제금액, 원가, 세금, 42maru 정산금액, 주말 용역비, 순정산액 |
| 메시지함 | 카톡에 붙여넣을 문구 (반투소프트·카페42·조남규 대표) |

상태: `계산서요청 → 음료요청 → 정산완료`

## 5. 정산 계산식 (확정)

메뉴별로 계산한 뒤 합산합니다. 수량은 **주문 수량**, 금액은 **단가표** 기준입니다.

| No. | 항목 | 계산 | 커피 25 | 티 25 |
|---|---|---|---|---|
| ① | 단가 | 판매가 / 원가 | 3,500 / 1,100 | 2,500 / 800 |
| ② | 수량 | 주문 수량 | 25 | 25 |
| ③ | 결제금액 / 원가 | ① × ② | 87,500 / 27,500 | 62,500 / 20,000 |
| ④ | 세금(10%) | 결제금액 × 10% | 8,750 | 6,250 |
| ⑤ | 42maru 정산금액 | 결제금액 − 원가 − 세금 | 51,250 | 36,250 |

- 일 합계: 51,250 + 36,250 = **87,500원**
- 주말(토·일): 음료 용역비 **40,000원(부가세 포함)**을 차감해 순정산액은 **47,500원**입니다.
- 순정산액이 음수이면 42maru가 마켓샐러드에 지급할 금액입니다.

## 6. 자동화 트리거

| # | 트리거 | 동작 |
|---|---|---|
| A | 10분마다: `[대관확정]` 메일 / 시트 메뉴 입력 | 대관원장 등록, 주말 판정, 캘린더 등록, 반투소프트 문구 생성 |
| B | 매일 09시: D-4 ~ D-1 중 음료요청 미발송 건 | 조남규 대표에게 `[음료요청]` 메일 |
| C | 10분마다: `[음료요청]` 회신 / 시트 메뉴 입력 | 음료주문·일별정산 기록, 카페42 문구 생성 |
| D | 매일 09시: D-1 미회신 건 | 담당자 알림 |
| E | 매월 1일 09시 | 전월 정산 리포트 |

## 7. 남은 확인 사항

- 공휴일에도 주말 용역비를 적용할지 정해야 합니다. 현재는 토·일만 적용합니다.
- 주문 수량과 실제 판매 수량이 다를 때 조정할지 정해야 합니다. 현재는 주문 수량으로 확정합니다.
