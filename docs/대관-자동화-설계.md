# 대관·카페 정산 자동화 설계

## 0. 관계자

| 역할 | 대상 | 소통 채널 |
|---|---|---|
| 대관 고객 | 바이스퀘어 조남규 대표 | 카톡 1:1 / 메일 |
| 세금계산서 발행 | 반투소프트 이근영 대표, 김동환 대표 | 카톡 단톡방 / 메일 |
| 음료 판매·정산 | 카페42 (마켓샐러드 법인) | 현장 POS / 메일 |
| 운영 | 42maru 대관 담당 | — |

## 1. 전체 흐름

```
[1] 일정 협의 (조남규 대표, 1:1)
      │  확정: "10/10 14:00~17:00 대관"
      ▼
[자동] 대관 원장(Google Sheet) 행 생성 + Google Calendar 등록
      ▼
[2] 세금계산서 발행 요청 (반투소프트 2인)  ← 자동 메일 + 카톡 붙여넣기용 문구
      ▼
[3] D-4 음료 사전 주문 요청 (조남규 대표)  ← 자동 메일
      │  회신: 메뉴·잔수
      ▼
[자동] 음료 주문 탭 기록 + 예상 정산액 계산 + 카페42에 주문 전달
      ▼
[대관 당일] 현장 POS 결제 (카페42 = 마켓샐러드 법인)
      ▼
[자동] 실제 결제 내역 반영 → 일별 정산서 생성 → 카페42·내부 공유
      ▼
[월말] 월간 정산 합계 리포트
```

## 2. 채널별 연동 가능 범위

| 채널 | 읽기(수신 파싱) | 쓰기(발송) | 비고 |
|---|---|---|---|
| **Gmail** | ✅ 가능 | ✅ 가능 | 자동화의 기준 채널로 사용 |
| **Google Calendar / Sheets** | ✅ | ✅ | 원장·일정·정산 계산 |
| **카톡 1:1 / 단톡방** | ❌ 공식 API 없음 | △ | 개인 대화방은 외부 읽기·쓰기 불가 |
| 카카오 "나에게 보내기" API | — | ✅ (본인에게만) | 담당자 알림용 |
| 카카오 알림톡(비즈 채널) | — | ✅ (고객에게) | 비즈니스 채널 + 발송대행사 계약 필요 |

**결론:** 기록·자동화의 기준은 **메일**로 둡니다. 카톡은 대화 채널로 계속 쓰되,
- 카톡으로 확정된 내용은 담당자가 **확정 메일 1통**(또는 시트 1행 입력)으로 시스템에 넣고,
- 시스템이 만든 **카톡 붙여넣기용 문구**를 단톡방에 복사해 공유합니다.
- 담당자에게 가는 알림은 카카오 "나에게 보내기"로 받을 수 있습니다.

## 3. 메일 규칙 (파싱을 위한 고정 양식)

제목 말머리만 지키면 자동으로 분류·파싱됩니다. Gmail 필터로 `대관` 라벨을 자동으로 붙입니다.

| 단계 | 제목 형식 | 보내는 사람 → 받는 사람 |
|---|---|---|
| 일정 확정 | `[대관확정] 2026-10-10 14:00-17:00 바이스퀘어` | 담당자 → 조남규 (CC: 대관 공용메일) |
| 계산서 요청 | `[계산서요청] 2026-10-10 바이스퀘어 대관료 OOO원` | 시스템 → 이근영·김동환 |
| 음료 요청 | `[음료요청] 2026-10-10 바이스퀘어` | 시스템 → 조남규 |
| 음료 회신 | 위 메일에 회신. 본문: `커피 25`, `아이스티 5` 형식 | 조남규 → 시스템 |
| 결제 내역 | `[결제내역] 2026-10-10` + POS 내역(본문 또는 첨부) | 카페42 → 시스템 |
| 정산서 | `[정산] 2026-10-10 카페42 → 42maru` | 시스템 → 카페42, 내부 |

## 4. 데이터 구조 (Google Sheet: `대관 관리`)

**탭 1. 대관원장**

| 대관ID | 대관일 | 시작 | 종료 | 고객사 | 담당자 | 주말여부 | 대관료(공급가) | 부가세 | 계산서요청일 | 계산서발행여부 | 음료요청일 | 상태 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

상태: `협의중 → 확정 → 계산서요청 → 음료요청 → 음료확정 → 완료 → 정산완료`

**탭 2. 단가표**

| 메뉴 | 판매가 | 원가 |
|---|---|---|
| 커피 | 3,500 | 1,100 |

**탭 3. 음료주문** (대관ID별 메뉴 1행)

| 대관ID | 메뉴 | 사전주문 수량 | 실제 결제 수량 | 판매가 | 원가 |
|---|---|---|---|---|---|

**탭 4. 일별정산** (아래 5장의 계산식)

## 5. 정산 계산식

메뉴별 합산 후 대관일 단위로 계산합니다.

| No. | 항목 | 계산 | 예시 (커피 25잔) |
|---|---|---|---|
| ① | 결제금액 | Σ 판매가 × 수량 | 87,500 |
| ② | 원가 | Σ 원가 × 수량 | 27,500 |
| ③ | 세금 | ① × 10% | 8,750 |
| ④ | 카페42 → 42maru 정산금액 | ① − ② − ③ | 51,250 |
| ⑤ | 주말 음료 용역비 (42maru → 마켓샐러드) | 토·일이면 40,000, 평일 0 | 40,000 |
| ⑥ | **순정산액** | ④ − ⑤ | **11,250** (주말) / 51,250 (평일) |

> 순정산액이 음수이면 42maru가 마켓샐러드에 지급할 금액입니다.

**확정이 필요한 사항**
1. 판매가 3,500원이 부가세 포함가라면 ③은 ① ÷ 11 (= 7,955원)이 맞습니다. 현재는 표 그대로 ① × 10%로 둡니다.
2. 주말 용역비 40,000원이 부가세 포함인지, 공휴일도 포함인지 정해야 합니다.
3. 정산 기준 수량은 사전주문 수량이 아니라 **실제 POS 결제 수량**으로 둡니다.

## 6. 자동화 트리거

| # | 트리거 | 동작 |
|---|---|---|
| A | `[대관확정]` 메일 수신 (또는 시트 행 입력) | 대관원장 행 생성, 주말 여부 판정, Calendar 등록 |
| B | A 직후 | 반투소프트 2인에게 `[계산서요청]` 메일 발송, 카톡 단톡방용 문구 생성 |
| C | 매일 09:00, 대관일 D-4 | 조남규 대표에게 `[음료요청]` 메일 발송 (회신 양식 포함) |
| D | `[음료요청]` 회신 수신 | 음료주문 탭 기록, 예상 정산액 계산, 카페42에 주문 전달 |
| E | 대관일 D-1 미회신 | 담당자에게 알림 (카톡 나에게 보내기 / 메일) |
| F | `[결제내역]` 수신 (또는 실제 수량 입력) | 일별정산 계산, `[정산]` 메일 발송 |
| G | 매월 1일 | 전월 일별정산 합계 리포트 발송 |

## 7. 구현 방식

| 방식 | 장점 | 단점 |
|---|---|---|
| **Google Apps Script** (권장, 1차) | 무료, Gmail·Sheets·Calendar 기본 연동, 시간 트리거 지원, 서버 불필요 | 자유 형식 문장 파싱은 약함 → 3장의 메일 양식으로 해결 |
| Claude Routine + Gmail/Calendar/Drive 커넥터 | 카톡 내보내기 txt나 자유 형식 메일도 이해 가능 | 계산 결과 검증 장치가 필요, 실행 시 커넥터 권한 필요 |

**권장안:** 정산 계산과 메일 발송은 Apps Script와 시트 수식으로 **결정적으로** 처리합니다. 양식이 지켜지지 않은 메일이나 카톡 대화 정리만 Claude가 보조합니다.

## 8. 연동 전 준비물

- [ ] 대관 공용 Gmail 계정 (또는 담당자 계정 + `대관` 라벨)
- [ ] 관계자 이메일: 조남규, 이근영, 김동환, 카페42 담당자
- [ ] 대관료 기준 (시간당/건당, 공급가 기준)
- [ ] 카페42 메뉴별 판매가·원가 전체
- [ ] 카페42 POS 결제 내역 공유 방식 (메일 본문, 엑셀, 사진)
- [ ] 5장의 확정 필요 사항 3건
- [ ] (선택) 카카오 디벨로퍼스 앱 등록: "나에게 보내기" 알림용
