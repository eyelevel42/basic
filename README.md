# 42maru 대관·카페42 정산 자동화

Google Sheet + Apps Script로 대관 일정 → 세금계산서 요청 → 음료 요청 → 카페42 정산을 자동화합니다.
설계 배경은 [docs/대관-자동화-설계.md](docs/대관-자동화-설계.md)를 참고하세요.

## 설치 (10분)

1. Google Drive에서 새 스프레드시트를 만듭니다. 이름은 `대관 관리`로 합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 [`apps-script/Code.gs`](apps-script/Code.gs)를 붙여넣습니다.
4. **+ → 스크립트**로 `Calc` 파일을 추가하고 [`apps-script/Calc.gs`](apps-script/Calc.gs)를 붙여넣습니다.
5. 프로젝트 설정(⚙)에서 시간대를 **Asia/Seoul**로 바꿉니다. 스프레드시트의 **파일 → 설정** 시간대도 같게 맞춥니다.
6. 편집기에서 함수 `setup`을 선택하고 **실행**합니다. Gmail·Calendar·Sheets 권한을 허용합니다.
7. 시트를 새로고침하면 상단에 **대관 자동화** 메뉴가 생깁니다.

`setup`은 시트 탭 5개(대관원장·음료주문·일별정산·단가표·메시지함)와 트리거 2개(10분마다 메일 확인, 매일 09시)를 만듭니다.

## 사용법

| 상황 | 할 일 | 자동으로 일어나는 일 |
|---|---|---|
| 카톡으로 일정 확정 | 조남규 대표에게 제목 `[대관확정] 2026-10-10 14:00-17:00 바이스퀘어`로 메일 발송 (또는 시트 메뉴 **카톡으로 확정된 대관 등록**) | 대관원장 등록, 캘린더 추가, 반투소프트 단톡방용 계산서 요청 문구가 메일과 메시지함 탭으로 옴 |
| 대관 4일 전 | 없음 | 조남규 대표에게 `[음료요청] … #R20261010-1` 메일 자동 발송 |
| 대표님이 메일로 회신 (`커피 25`, `티 25`) | 없음 | 음료주문·일별정산 기록, 카페42 전달용 주문·정산 문구가 메일로 옴 |
| 카톡으로 수량을 받은 경우 | 시트 메뉴 **음료 수량 직접 입력** | 위와 동일 |
| 대관 하루 전까지 회신이 없을 때 | 알림 메일 확인 | — |
| 매월 1일 | 없음 | 전월 정산 리포트 메일 |

카톡 단톡방(반투소프트)과 카페42 전달은 **메시지함 탭이나 알림 메일의 문구를 복사해 붙여넣는** 방식입니다. 카카오는 개인 대화방 API를 제공하지 않습니다.

## 정산 규칙

메뉴별로 계산한 뒤 합산합니다. 금액은 단가표 탭 기준이며, 수량은 주문 수량을 씁니다(POS 내역 미사용).

- 결제금액 = 판매가 × 수량
- 원가 = 원가 × 수량
- 세금 = 결제금액 × 10%
- 42maru 정산금액 = 결제금액 − 원가 − 세금
- 주말(토·일)에는 음료 용역비 40,000원(부가세 포함)을 차감합니다.
- 순정산액 = 42maru 정산금액 − 주말 용역비

| 예시 | 커피 25 | 티 25 | 합계 | 주말 차감 | 순정산 |
|---|---|---|---|---|---|
| 평일 | 51,250 | 36,250 | 87,500 | 0 | **87,500** |
| 주말 | 51,250 | 36,250 | 87,500 | −40,000 | **47,500** |

메뉴나 단가가 바뀌면 **단가표 탭만 수정**하면 됩니다. 음료 요청 메일 양식에도 자동으로 반영됩니다.
